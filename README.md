# python-projekte

Discord bot built with discord.py as part of the Developer Akademie Python course (BACKEND 03).

## Features

- Level roles
- Timeout and automod
- Configurable settings

## Setup

1. Create and activate a virtual environment:

   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

2. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

3. Create a `.env` file with your bot token:

   ```
   DISCORD_TOKEN=your-token-here
   ```

4. Start the bot:

   ```powershell
   python bot.py
   ```
